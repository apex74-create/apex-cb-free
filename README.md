# Apex Signal · the field-app foundry

One shared field frame, three addresses: [TinyRadr](https://tinyradr.com) is the depot and Enphase weather entrance, [Encrypted CB](https://encryptedcb.com) is the urban Sovereign CB entrance, and [Cast Net Mesh](https://castnetmesh.com) is the event-mesh entrance. Their `www` addresses serve the same respective identities. The free CB and basic field tools run in a browser/PWA; paid features require server-issued access. This is not a claim that browser-only hardware links or background audio work on every device.

## Three $9.99 toy editions

The depot links to [UAP Field Station](https://tinyradr.com/uap), [Halloween Ghost Station](https://tinyradr.com/ghost), and [Mystic 9 Ball](https://tinyradr.com/mystic-nine). Each is offered at $9.99 once in the sandbox catalogue with its own purchase check. Basic radar, map, weather and CB tools remain free. Camera, microphone and motion readings depend on device permission and availability. A rotating time-series is not a 3D room scan; neither station detects paranormal or extraterrestrial causes. The nine ball is a symbolic clock-phase game, not a prediction. End-to-end checkout and licence delivery are still to be verified before claiming a completed sale; production payments require go-live.

The founder observed three app experiences assembled in about 18 minutes using the reusable Foundry, vibe coding in Lovable and AI-agent collaboration. That is an account of one build session, not a repeatable engineering benchmark. The Foundry pattern is policy + permitted engines + input adapters + labeled evidence + a shared application skin; new screens don't create new scientific measurements.

## Developer bait pile

Start with the [filtered public fork](https://github.com/apex74-create/apex-cb-free), not this private working tree. Run its documented setup locally, improve keyboard and touch ergonomics, offline states, accessible sensor-permission prompts, device compatibility tests, or visual skins without changing the carrier contract. Send a pull request with a reproduction and screenshots. The contribution ladder runs E0–E4: public shell exploration, tested improvements, reviewed integrations, trusted collaborations and separately licensed protected work. It is an invitation to make the free shell cooler, **not** a promise of automatic access to proprietary engines. Request an API key through the [manual application page](https://tinyradr.com/api-access); keys are individually issued, metered and revocable. See the public fork's licence terms before commercial use.

The proprietary weather/defense engine math, daisy-chain relay, private device binding, token costs, operator scripts, secrets and customer records do **not** belong in the public fork. See `docs/OPEN_CORE_MANIFEST.md` before any mirror sync. Do not push this private checkout directly. Contributions are welcomed under the terms in that manifest; confirm the public fork's actual licence file before reuse.

## Work lanes

- **Lovable/PWA:** domain-aware installation, storefront, CB/weather/event screens, local evidence and server-issued access.
- **Copilot/native:** Android/iOS containers, physical PTT, background audio, USB/BLE and validated external sensor arrays. See the dated native handoff for the next mergeable deliverable.
- **Protected service:** licensed engine calls and fulfilment; never put secret math in a forkable UI.

Frontend updates need **Publish → Update** to reach the public domains; this README change alone does not deploy them. Site pageviews are not microphone key-ups. The reported free-web-install count is browser-reported, deduplicated by a local receipt, and is not a count of unique people, APK downloads or earlier installs.
