# Apex CB Shell — Contributor Ladder & Badges

This repo is the free, forkable shell of Apex Signal. Contributions are
welcome — and they are how you climb. Each level is awarded by the
owner as a PR label and recorded on the contributors wall in the README.

## The ladder

| Level | Badge | How you earn it | What it opens |
| --- | --- | --- | --- |
| **Contributor** | `level:contributor` | One merged PR (fix, docs, UI polish) | Name on the contributors wall |
| **Builder** | `level:builder` | Three merged PRs, or one merged feature with tests | Access to builder-only discussion threads; early review of new shell features |
| **Operator** | `level:operator` | Sustained contributions + field testing reports (hardware, runay, deployments) | Operator-package discount; input on the shell roadmap |
| **Assembly unlock** | `level:assembly` | By invitation — significant, trusted work | The customizable skeleton frame + GUI unification engine (side-tab frame, per-skin accents) for your own builds |
| **Daisy-chain licence** | `level:daisy-chain` | Top of the ladder, invitation only | Licensed access to the handset-to-handset daisy-chain relay — the technology that is never in this repo }

## Rules

- Badges are awarded by the owner only. Asking is fine; demanding is not.
- Each level builds on the last — no skipping.
- Breaking the contributor terms (SEE CONTRIBUTING.md) forfeits badges.
- The proprietary engines are never a prize. Even the top level is a
  licence, not outright ownership.

## Good first issues

Look for the `good first issue` label. These are deliberately small,
self-contained tasks that touch only the shell — perfect first PRs.
